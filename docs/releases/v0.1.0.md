# v0.1.0

首个可下载版本，提供通过现有代理链路使用的 TCP 反向端口映射。

- 一个可执行文件提供客户端与服务端，支持静态 SSH、Web 等 TCP 映射。
- 支持直接 TCP 和 HTTP CONNECT，可配合独立运行的 AnyTLS、Hysteria 2 等外层代理。
- 提供身份与会话校验、一次性连接配对、保活重连、超时和连接数量上限。
- Linux 原生 TCP 保留 Go 的 splice 与回退；其他平台使用池化分级缓冲，保留 CONNECT 读超前数据。
- 提供 Linux、Windows、macOS 的 amd64 / arm64 下载包、示例配置和 `SHA256SUMS`。

使用说明见 [README](https://github.com/Jacko-John/sertun#readme)，测试范围与本地 frp / Mihomo 对照见 [验证记录](https://github.com/Jacko-John/sertun/blob/v0.1.0/VALIDATION.md)。

sertun 自身不加密传输，需配合外层代理或可信网络。当前仅支持 TCP，每条业务使用独立回连；控制会话中断后，已断开的 TCP 会话不会恢复。公网、丢包条件及外层半关闭兼容性仍需补充验证。

60 秒空闲通道复用已列入 [后续规划](https://github.com/Jacko-John/sertun/blob/v0.1.0/ROADMAP.md)，不属于本版功能。
