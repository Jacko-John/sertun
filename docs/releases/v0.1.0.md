# v0.1.0

这是第一个可以下载的版本，提供通过现有代理链路使用的 TCP 反向端口映射。

- 一个可执行文件同时当客户端和服务端，支持静态 SSH、Web 等 TCP 映射。
- 支持直接 TCP 和 HTTP CONNECT，可以配合独立运行的 AnyTLS、Hysteria 2 等外层代理。
- 有身份和会话校验、一次性连接配对、保活重连、超时和连接数量上限。
- Linux 原生 TCP 保留 Go 的 splice 与回退；其他平台用池化分级缓冲，并保留 CONNECT 的读超前数据。
- 提供 Linux、Windows、macOS 的 amd64 / arm64 下载包、示例配置和 `SHA256SUMS`。

用法见 [README](https://github.com/Jacko-John/sertun#readme)，测试范围和本地 frp / Mihomo 对照见 [验证记录](https://github.com/Jacko-John/sertun/blob/v0.1.0/VALIDATION.md)。

sertun 自己不加密传输，要配合外层代理或可信网络。目前只支持 TCP，每条业务单独回连；控制会话中断后，已经断开的 TCP 会话不会恢复。公网、丢包条件和外层半关闭兼容性还没验证。

60 秒空闲通道复用已经列进[后续规划](https://github.com/Jacko-John/sertun/blob/v0.1.0/ROADMAP.md)，不在这个版本里。
