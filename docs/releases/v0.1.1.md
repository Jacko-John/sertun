# v0.1.1

维护版本。产品转发和协议行为与 v0.1.0 相同。

- 整理服务端和客户端控制流程，补齐包、函数和所有权注释。
- 新增监听器失败回收、非法写入计数和复制前缀保留测试；控制帧和配置解析加入 fuzz。
- benchmark 工具修正源码来源记录、按场景准备外部工具、TCP/UDP 端口预留、内存字段格式和结果文件清理。
- 更新项目文档和开发规则，加入格式、静态分析、race、fuzz 和热路径基准的硬门槛。
- 在 Linux 容器内完成测试、race、复制微基准和 splice 核对。

仍然只支持 TCP，每条业务使用独立回连；控制会话中断后，已断开的 TCP 会话不会恢复。传输加密由外层代理或可信网络承担。用法见 [README](https://github.com/Jacko-John/sertun#readme)，验证范围见 [验证记录](https://github.com/Jacko-John/sertun/blob/v0.1.1/VALIDATION.md)。
